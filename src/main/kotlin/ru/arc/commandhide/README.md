# CommandHide

`CommandHideModule` блокирует выполнение и скрывает tab-complete команд по
группам из `plugins/ARC/modules/command-hide.yml`.

## Группы и permissions

Каждый ключ `groups.<id>` автоматически получает permission
`arc.command.hide.<id>`. Наличие permission добавляет игроку ограничения этой группы.
Несколько разрешённых групп объединяются. `inherits` разворачивается при
загрузке конфига, поэтому дочерняя группа получает все шаблоны родителей без
дополнительного обхода наследования на каждой команде.

`arc.command.hide.bypass` отключает все ограничения и предназначен для сотрудников.

## Быстрое управление игроком

Администратор с `arc.command.hide.admin` может управлять прямой постоянной
выдачей настроенного `bypass-permission`:

```text
/arc commandhide allow <игрок>
/arc commandhide restrict <игрок>
/arc commandhide status <игрок>
```

Команда принимает только точное имя игрока, который сейчас находится на этом
Paper-сервере. ARC берёт его подтверждённый UUID, меняет permission через
LuckPerms API без консольной команды, сбрасывает policy cache и сразу вызывает
`Player.updateCommands()`. Изменение сохраняется в LuckPerms и поэтому
переживает переподключение.

`restrict` удаляет только глобальную постоянную выдачу, которой управляет эта
команда. Контекстные, временные и наследуемые права не удаляются; если другое
правило всё ещё даёт bypass, команда сообщает об этом явно.

Владение выдачей фиксируется отдельным meta-маркером
`arc-commandhide-managed-bypass` в LuckPerms. Если ARC встречает чужую прямую
выдачу или прямой запрет того же permission, он не присваивает её себе и не
перезаписывает, а просит администратора разрешить конфликт в LuckPerms. Если
игрок успел переподключиться во время сохранения, текущий сеанс повторно
находится по UUID; если вышел — дерево команд обновится при следующем входе.

## Шаблоны

Команда разбивается на слова без начального `/` и сравнивается без учёта
регистра:

- `literal` — одно точное слово;
- `*` — ровно одно произвольное слово;
- `**` — ноль или больше оставшихся слов; разрешён только в конце.

Шаблон без wildcard сравнивает точное число слов. Поэтому для полной ветки
используется `plugins **`, а для одного действия — `example admin reload`.
При `strip-command-namespace: true` первый namespace снимается: `plugins`
одновременно покрывает `bukkit:plugins`.

`hide-namespaced-roots: true` отдельно скрывает все корневые
`plugin:command`-дубли у игроков с активной hide-группой. Это правило влияет
только на видимость: обычный алиас остаётся доступен, а namespaced-вызов не
блокируется без явного шаблона в `commands`.

## Выполнение и tab-complete

`PlayerCommandPreprocessEvent` блокирует выполнение. `PlayerCommandSendEvent`
скрывает корневые команды, `TabCompleteEvent` фильтрует серверные подсказки, а
персональное Brigadier-дерево удаляет поддеревья, полностью покрытые шаблоном с
`**`, и точные заблокированные leaf-команды. Если точный узел имеет разрешённые
дочерние команды, сам узел остаётся в дереве, чтобы не скрыть разрешённую ветку.

Шаблоны компилируются в token trie. Набор групп игрока кэшируется и
переиспользует общую скомпилированную policy для одинаковых сочетаний
permissions. Кэш обновляется при отправке command tree, reload и по TTL.
После завершения join lifecycle ARC повторно отправляет дерево на следующем
тике, чтобы первая сборка до загрузки permissions не осталась у клиента.
