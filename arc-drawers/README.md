# ArcDrawers

Серверные бочки с 1, 2 и 4 отделениями для обычного Minecraft-клиента. Требуются
Paper/Purpur, ArcCore и PacketEvents. Рецепты открывает `/arcdrawers`.

| Действие | Управление |
|---|---|
| Автоматически положить или забрать | Воронка, направленная в бочку, или воронка под ней |
| Положить стопку | ПКМ по отделению |
| Сложить все такие предметы из инвентаря | Двойной ПКМ по отделению |
| Взять предмет или стопку | ЛКМ или приседание + ЛКМ |
| Посмотреть количество и вместимость | ПКМ пустой рукой |
| Закрепить образцы, в том числе в опустевших отделениях | ПКМ ключом фиксации по фасаду |
| Показать или скрыть числа | ПКМ ключом индикации по фасаду |
| Поставить улучшение ×2, ×4, ×8 или утилизацию | ПКМ улучшением по фасаду |
| Снять улучшения | Приседание + ПКМ пустой рукой по боку |
| Снять пустую бочку | Сломать с любой стороны, кроме фасада, либо топором в присяде с фасада |

Базовая вместимость отделения — 32, 16 или 8 стопок соответственно.
Улучшение утилизации уничтожает излишек только при совпадении с образцом.

## Сборка

Из корня ARC на Java 25:

```sh
./gradlew -p arc-drawers test shadowJar
python3 ../arc-core/scripts/verify_consumer_architecture.py arc-drawers --jar build/libs/ArcDrawers-0.1.0.jar
```

Расположение, настройки, количества и образцы сохраняются в Paper PDC чанка.
Запись бочки занимает от 4 до 10 байт без учёта ключей NBT и образцов предметов.
Остатки сохраняются при обычном сохранении мира. У бочек нет отдельной базы
или журнала и нет межсерверной синхронизации.
