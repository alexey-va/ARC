# Главное меню ARC

`/menu` — основной вход. `/help` и `/arc help` остаются совместимыми.
Меню использует опубликованный `arc-core-paper-menu` 2.4.5: нативные диалоги
для поддерживаемых клиентов и инвентарный режим совместимости.

## Навигация

Цвет обозначает роль, а не конкретный раздел: голубой — навигация и обычные
действия, золотой — заголовки, зелёный — подтверждение, красный — удаление,
отклонение и ошибки, серый — возврат и вторичный текст. Равнозначные кнопки
в обеих колонках имеют одинаковый цвет. Значения в информационных блоках белые.

В корне остаются десять разделов: «Про меня», «Поиск», «Телепортация»,
«Приват», «Активности», «Развитие», «Торговля», «Игроки», «Технологии» и
«Настройки». Вторичные возможности находятся внутри разделов.

- «Игроки» показывает сеть через ARC PlayerManager, по 12 записей на страницу.
  Доступны фильтр по нику, переключение на текущий сервер и обновление.
  Возврат из карточки игрока, сообщения и подтверждения перевода сохраняет
  фильтр и страницу; при изменении онлайна номер страницы ограничивается заново.
- Закрытие внешнего игрового инвентаря возвращает в открывший его раздел.
  Возврат одноразовый; вложенные инвентари остаются в той же цепочке.
  Новый переход через главное меню отменяет прежний возврат.
- Настройки чата и Trails обновляются после команды на том же экране.
  Состояния берутся у владельцев механик, отказ команды не имитирует успех.
- «Про меня → Избранное и недавнее → Выбрать из каталога» позволяет выбрать
  действие без знания команды. Четыре закрепления и шесть недавних действий
  хранятся через существующий Redis CAS. Пятое закрепление не вытесняет старое:
  сначала нужно освободить место. При недоступном Redis остальные разделы работают.
- «Активности → Чем заняться» содержит шесть подборок с пояснениями;
  «Играть вместе» ведёт также в сетевой список игроков.
- «Поиск → Что случилось?» содержит проверки и инструкции по телепортации,
  приватам, поиску игрока, предметам и командам. Эти проверки не заменяют
  точный отказ плагина в чате и не обещают автоматически восстановить данные.

## Контракт реализации

Тексты находятся в `src/main/resources/modules/help-center.yml`; новые ключи
добавляются через существующий merge defaults. Рабочие overrides двух основных
нод находятся в ops-репозитории. Обработчики команд повторно проверяют доступность
каталога; права, стоимость и подтверждения остаются у плагинов-владельцев.

`HelpCenterNavigation` разделяет поколение перехода между основным и вложенным
контроллерами: позднее чтение Redis или домов не заменяет более новый экран.
Состояние очищается при выходе игрока и остановке модуля. Идентификаторы кнопок
нормализуются под контракт Dialog API; пустые разделы предлагают поиск.

Проверки: `./gradlew test --tests 'ru.arc.helpcenter.*'`, затем `./gradlew test shadowJar`.
`HelpCenterScreensTest` проверяет реальные модели экранов, нажатия, возвраты,
пагинацию, пустые разделы и устаревшие асинхронные ответы. Превью текста и
геометрии: `./scripts/render-visual-preview --ops-root /absolute/path/to/ruscrafting-ops`.
Рендер показывает тексты и кнопки; поля ввода и отдельное размещение кнопки
выхода требуют проверки в клиенте Minecraft.
