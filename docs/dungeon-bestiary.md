# Бестиарий данжей

Вход: карточка данжа в каталоге → «Бестиарий»; внутри похода — та же кнопка
в панели `Shift + F`. Все экраны используют native Paper Dialog и общую историю ARC.

Запись открывается после победы для игрока, который нанёс положительный урон,
находится в том же мире и участвует в инстансе. Creative, наблюдатели, игроки
рядом без урона и сработавший anti-exploit не открывают запись. Фазы одного босса
используют общий ключ первой формы. Призванные противники имеют собственные записи.
До открытия скрыты имя, способности и добыча; доступны общий размер каталога
и число изученных противников. Старый общий счётчик убийств EliteMobs не содержит
истории по видам, поэтому прошлые убийства автоматически не восстанавливаются.

`DungeonBestiaryCatalog` читает загруженные конфигурации EliteMobs и строит
каталог без создания существ, бросков добычи и исполнения команд/способностей.
Шанс уникального предмета сопровождается условиями доступа и сложности;
случайное снаряжение и другие условные источники обозначаются отдельно.
Проценты отображают действующие правила EliteMobs, а не статистическую оценку
из малого числа убийств. Изменения конфигураций подхватываются вместе с нативным
обновлением реестра EliteMobs.

`DungeonBestiaryProgressStore` хранит монотонный набор открытий в общем Redis:
`arc.dungeon_bestiary.<UUID>`, поле — точное имя конфигурации с `.yml`, значение — `1`.
Атомарная запись предотвращает повторное открытие при конкуренции серверов;
файлы игроков, кошельки, инвентари и награды не изменяются. Нет TTL или сброса
при новом походе. Чтение/запись асинхронны; уведомление отправляется после
подтверждения хранилища. При сбое выполняются две отложенные повторные попытки;
исчерпание попыток отражается в логе и сообщении игроку.

Экономика: неизменные шансы/количества/лимиты выдачи; прямое изменение
`vault = 0`, `tokens = 0`, кристаллов `= 0`, XP `= 0`, предметов `= 0`.
Переход SELL EconomyShopGUI к контрактам не затронут.

Проверки: `DungeonBestiaryCatalogTest`, `DungeonBestiaryProgressTest`,
`DungeonBestiaryTest`, `DungeonBestiaryMenusTest` и существующие
`DungeonAdventureMenusTest`/`DungeonPanelTest`. Проверки исходников и макетов
не доказывают внешний вид в обычном Minecraft-клиенте.
